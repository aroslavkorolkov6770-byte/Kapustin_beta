# Kapustin_beta: сокращённый бета-тест

Версия от 1 ноября 2026 года. Основа — приложенный `tea-app-main (19).zip` с сохранением его учебного наполнения.

## Что изменено

- Администратор создаёт сотрудника и выдаёт ему логин и пароль. Сотрудник сразу входит в личный кабинет без отдельной регистрации.
- Прежние записи с незавершённой регистрацией также входят после правильного ввода пароля.
- Поля электронной почты, телефона и соцсети удалены из форм входа и профиля. Имя, аватар и смена пароля сохранены.
- Сообщения администратора, уведомления о документах и дедлайны доступны внутри кабинета.
- Кнопка называется «Отправить уведомление», как в исходном проекте.
- Алгоритмы отправки писем и Push, браузерная подписка, зависимости и настройки внешней доставки удалены. Прежние POST-маршруты возвращают HTTP 410 без отправки.

## Что сохранено

Все 125 файлов исходного проекта остаются в поставке. Все шесть файлов данных совпадают с исходным архивом побайтно. Сохранены 25 тем, 10 разделов базовых материалов, готовые учебные тесты, мини-тесты каталога, административные шаблоны аттестаций, учётные записи и остальные исходные данные.

Редакторы, назначение тестов, документы, каталог, роли и другие модули продолжают работать. Реквизиты исходного проекта сохранены.

## Запуск

Нужны Node.js 20.9 или новее и npm. Команды выполняются из корня проекта.

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env.local`, если собственного файла окружения ещё нет.
3. Задайте собственный `AUTH_SECRET` длиной не менее 32 символов. Случайное значение можно получить командой:

   ```powershell
   node -e "console.log(require('node:crypto').randomBytes(48).toString('hex'))"
   ```

4. Задайте `APP_ORIGIN` равным адресу запуска, например `http://127.0.0.1:3000`.
5. Для разработки выполните `npm run dev`. Для готовой сборки выполните `npm run build`, затем `npm run start`.
6. Откройте `/login` и используйте учётную запись администратора исходной установки. Администратор создаёт новые записи сотрудников и выдаёт доступ.

Данные исходного архива включены в поставку. При работе с существующей установкой сохраняйте её пользовательские данные и окружение.

## Проверка после запуска

Создайте сотрудника в админке и войдите по выданным данным. Дополнительной формы регистрации и контактных полей быть не должно. Отправьте сообщение через «Отправить уведомление» и откройте колокольчик в кабинете получателя. Убедитесь, что прежние темы и готовые тесты доступны.

Результаты проверки этой версии приведены в `BETA_VERIFICATION.md`.
