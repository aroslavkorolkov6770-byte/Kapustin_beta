# Kapustin_beta: сокращённый бета-тест

Версия от 1 ноября 2026 года из `tea-app-main (19).zip`. Все исходные темы, готовые тесты, базовые материалы, каталог и данные сохранены.

Сотрудник входит по выданным логину и паролю без дополнительной регистрации. Поля почты, телефона и соцсети удалены. Уведомления поступают только в личный кабинет; кнопка «Отправить уведомление» сохраняет своё название.

Репозиторий: [Kapustin_beta](https://github.com/aroslavkorolkov6770-byte/Kapustin_beta), ветка `main`. Исходники находятся сразу в корне: `app/`, `public/`, `data/`, `package.json` и `package-lock.json`.
